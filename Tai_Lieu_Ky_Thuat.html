Phần 1

Tổng quan & cấu trúc dự án

Repo này là thư viện hạ tầng dùng chung cho nhiều game Godot trên Android. Mỗi tính năng native (thông báo, đăng nhập, thanh toán, analytics, quảng cáo) được viết một lần bằng Java, đóng gói thành .aar, rồi bọc trong một Autoload GDScript. Phía game chỉ cần gọi TênAddon.hàm().

Code chia làm bốn tầng. Lệnh đi từ trên xuống, kết quả bất đồng bộ đi từ dưới lên. Tầng game không bao giờ gọi thẳng vào Java: mọi lời gọi đều qua wrapper GDScript, vì wrapper là nơi có Safe-Mock.

Java custom_plugin/

Mã nguồn native, mỗi plugin là một project Gradle riêng. Một lớp Facade kế thừa GodotPlugin chỉ lo nhận lệnh và chuyển xuống Module con. Module con mới là nơi gọi SDK. Kết quả build: build/outputs/aar/<Tên>-release.aar.

GDScript addons/

Phần game thực sự dùng. Gồm file .aar đã build, plugin.cfg, export_plugin.gd (khai báo AAR, Maven và manifest khi export) và một wrapper Autoload có Safe-Mock.

Luồng dữ liệu & cơ chế queue chống Cold Start

Callback của Android (Credential Manager, Billing, mở app từ thông báo) chạy trên UI thread và có thể tới trước khi engine Godot nạp xong. Nếu gọi emitSignal() lúc đó, app văng vì signal của plugin chưa được đăng ký. Các addon mới (AndroidUtil, Google Sign-In, Google Billing) xử lý theo cùng một mẫu:

Java · UI thread1. Callback tớiChuyển kết quả thành Dictionary rồi queue.offer().
→
Java2. Rung chuôngChỉ emit khi mainLoopStarted, qua runOnRenderThread, signal không kèm dữ liệu.
→
GDScript3. Rút queuewhile has_pending_*(): pop_pending_*()
→
GDScript4. Phát signalTách thành các signal có nghĩa cho game.
iVì sao không mất dữ liệu khi cold start?

Queue là nơi duy nhất giữ dữ liệu, còn signal chỉ là chuông báo. Nếu chuông không kêu được (engine chưa sẵn sàng), dữ liệu vẫn nằm trong queue. Trong _ready(), wrapper đợi một frame (process_frame với CONNECT_ONE_SHOT) để các node khác kịp connect signal, rồi tự rút queue một lần. Ngoài ra, onGodotMainLoopStarted() ở phía Java cũng rung chuông lại nếu queue còn dữ liệu.

Hướng dẫn chi tiết 5 Addons

Mỗi addon gồm: mục đích, danh sách API, code mẫu gọi từ game, hành vi Safe-Mock trên PC và các lưu ý riêng. Code mẫu chỉ minh hoạ cách gọi. Tên sản phẩm, text và phần thưởng là của game, addon không biết tới.

1 · AndroidUtil Queue

Autoload: AndroidUtil
Java: com.godot.androidutil.GodotAndroidUtilPlugin
Quyền: POST_NOTIFICATIONS · ACCESS_NETWORK_STATE · RECEIVE_BOOT_COMPLETED

Mục đích: hẹn thông báo cục bộ chạy được cả khi offline hoặc app đã đóng (thông qua AlarmManager và NotificationReceiver, tự đặt lại lịch sau khi máy khởi động lại). Addon cũng đọc thông số thiết bị: RAM, CPU, pin, loại mạng, phiên bản app.

Code mẫu

# Kết nối sớm để không bỏ lỡ thông báo đã mở app lúc cold start
func _ready() -> void:
	AndroidUtil.notification_opened.connect(_on_notification_opened)
	AndroidUtil.notification_permission_result.connect(_on_permission_result)
	if not AndroidUtil.are_notifications_enabled():
		AndroidUtil.request_notification_permission()


# Text và thời gian hẹn do game quyết định, addon chỉ chuyển xuống Android
func _schedule_comeback_reminder(title: String, body: String) -> void:
	const REMINDER_ID := 1001
	const DELAY_SECONDS := 8 * 60 * 60
	AndroidUtil.cancel_notification(REMINDER_ID)
	AndroidUtil.schedule_notification(REMINDER_ID, title, body, DELAY_SECONDS, "open_daily")


# Payload do chính game đặt nên game tự định tuyến màn hình
func _on_notification_opened(id: int, payload: String) -> void:
	print("Mở từ thông báo ", id, " payload=", payload)


func _on_permission_result(granted: bool) -> void:
	print("Quyền thông báo: ", granted)


# Hạ chất lượng đồ hoạ trên máy yếu
func _apply_quality_preset() -> void:
	var info := AndroidUtil.get_device_info()
	if info.get("is_low_memory", false) or int(info.get("total_ram_mb", 0)) < 3072:
		get_viewport().msaa_3d = Viewport.MSAA_DISABLED
✓Safe-Mock trên PC/Editor

are_notifications_enabled() trả về true. request_notification_permission() phát ngay notification_permission_result(true). schedule_notification() trả về true nhưng không hẹn gì. get_device_info() trả dữ liệu giả lập (8192 MB RAM, network_type="WIFI", số lõi CPU thật của PC). notification_opened không bao giờ phát.

2 · Google Sign-In Queue Credential Manager

Autoload: GoogleSignIn
Java: com.godot.googlesignin.GodotGoogleSignInPlugin
SDK: androidx.credentials 1.3.0 · googleid 1.1.1

Mục đích: đăng nhập Google qua Credential Manager (GetSignInWithGoogleOption, kiểu đăng nhập khi người chơi bấm nút "Sign in with Google"), trả về thông tin người dùng và id_token để server game xác thực. Callback của Credential Manager được đưa vào queue rồi mới phát ra GDScript, không còn dùng onMainActivityResult.

!Thay đổi phá vỡ tương thích khi lên v0.2.0 (từ GoogleSignIn API cũ)

  • Mã lỗi đổi từ dạng "12501:SIGN_IN_CANCELLED" sang "CANCELLED". Các đoạn kiểm tra begins_with("12501") phải sửa lại.
  • Cấu trúc user_data giữ nguyên 5 trường như cũ.

# Danh sách sản phẩm là dữ liệu của game, không đặt trong addon
const CONSUMABLE_IDS: PackedStringArray = ["gem_pack_small", "gem_pack_large"]
const NON_CONSUMABLE_IDS: PackedStringArray = ["remove_ads"]

var _granted_tokens := {}


func _ready() -> void:
	GoogleBilling.connected.connect(_on_connected)
	GoogleBilling.disconnected.connect(GoogleBilling.start_connection)
	GoogleBilling.product_details_received.connect(_on_products)
	GoogleBilling.purchase_updated.connect(_handle_purchases)
	GoogleBilling.unconsumed_purchases_received.connect(_handle_purchases)
	GoogleBilling.purchase_consumed.connect(_on_consumed)
	GoogleBilling.purchase_failed.connect(_on_billing_error)
	GoogleBilling.start_connection()


# Quét đơn kẹt trước, sau đó mới lấy giá cho cửa hàng
func _on_connected() -> void:
	GoogleBilling.query_unconsumed_purchases()
	GoogleBilling.query_product_details(CONSUMABLE_IDS + NON_CONSUMABLE_IDS)


func _on_products(products: Array) -> void:
	for p in products:
		print(p["product_id"], " = ", p["price"])


# Chỉ trao thưởng đơn đã trả tiền, chưa trao và chưa acknowledge
func _handle_purchases(purchases: Array) -> void:
	for p in purchases:
		var token: String = p["purchase_token"]
		if p["purchase_state"] != GoogleBilling.PURCHASE_STATE_PURCHASED or p["is_acknowledged"] or _granted_tokens.has(token):
			continue
		_granted_tokens[token] = true
		_grant_reward(p["product_id"])
		_finish_purchase(p["product_id"], token)


# Item tiêu hao phải consume để mua lại được, item mua 1 lần chỉ acknowledge
func _finish_purchase(product_id: String, token: String) -> void:
	if product_id in NON_CONSUMABLE_IDS:
		GoogleBilling.acknowledge_purchase(token)
	else:
		GoogleBilling.consume_purchase(token)


func _grant_reward(product_id: String) -> void:
	print("Trao thưởng cho ", product_id)


func _on_consumed(token: String) -> void:
	print("Đã consume ", token)


func _on_billing_error(code: int, message: String) -> void:
	push_warning("Billing lỗi %d: %s" % [code, message])
✓Safe-Mock trên PC/Editor

start_connection() phát connected, sau đó is_ready() trả về true. query_product_details() trả giá giả "$0.99" / 990000 micros / USD cho từng id. purchase() luôn thành công, đơn ở trạng thái PURCHASED và có token mock_token_<id>_<ms>. consume_purchase() phát purchase_consumed, acknowledge_purchase() phát purchase_acknowledged. query_unconsumed_purchases() trả mảng rỗng. Mọi signal đều phát qua call_deferred.

!Chống trao thưởng 2 lần

Cùng một đơn có thể về qua cả purchase_updated lẫn unconsumed_purchases_received (ví dụ app quét lại trước khi consume xong). Luôn khử trùng lặp bằng purchase_token. Trong game thật nên để server xác minh original_json + signature và đánh dấu token đã dùng.

1.2 · Facade với queue chống Cold Start

Facade chỉ nhận lệnh và chuyển xuống Module. Kết quả đi qua pushEvent(), không bao giờ emitSignal trực tiếp từ callback.

package com.godot.myfeature;

import android.app.Activity;
import android.util.Log;
import androidx.annotation.NonNull;
import com.godot.myfeature.core.MyFeatureModule;
import org.godotengine.godot.Dictionary;
import org.godotengine.godot.Godot;
import org.godotengine.godot.plugin.GodotPlugin;
import org.godotengine.godot.plugin.SignalInfo;
import org.godotengine.godot.plugin.UsedByGodot;

import java.util.HashSet;
import java.util.Set;
import java.util.concurrent.ConcurrentLinkedQueue;

public class GodotMyFeaturePlugin extends GodotPlugin {
    private static final String TAG = "GodotMyFeature";
    private static final String SIGNAL_EVENT_READY = "event_ready";

    private final Activity activity;
    private MyFeatureModule module;

    // Callback SDK chạy ở UI thread, GDScript rút ở render thread
    private final ConcurrentLinkedQueue<Dictionary> pendingEvents = new ConcurrentLinkedQueue<>();

    // Cold start: chưa được emitSignal khi engine chưa đăng ký signal của plugin
    private volatile boolean mainLoopStarted = false;

    public GodotMyFeaturePlugin(Godot godot) {
        super(godot);
        this.activity = getActivity();
    }

    @NonNull
    @Override
    public String getPluginName() {
        return "GodotMyFeature";
    }

    @NonNull
    @Override
    public Set<SignalInfo> getPluginSignals() {
        Set<SignalInfo> signals = new HashSet<>();
        signals.add(new SignalInfo(SIGNAL_EVENT_READY));
        return signals;
    }

    @Override
    public void onGodotMainLoopStarted() {
        super.onGodotMainLoopStarted();
        mainLoopStarted = true;
        if (!pendingEvents.isEmpty()) emitEventReady();
    }

    // Lưu vào queue rồi chỉ rung chuông, dữ liệu luôn để GDScript tự rút
    private void pushEvent(Dictionary event) {
        pendingEvents.offer(event);
        emitEventReady();
    }

    // Bỏ qua khi engine chưa sẵn sàng, dữ liệu vẫn nằm trong queue
    private void emitEventReady() {
        if (!mainLoopStarted) return;
        runOnRenderThread(() -> {
            try {
                emitSignal(SIGNAL_EVENT_READY);
            } catch (IllegalArgumentException e) {
                Log.w(TAG, "emitSignal thất bại: " + e.getMessage());
            }
        });
    }

    // Tạo module muộn vì activity có thể null lúc plugin khởi tạo
    private MyFeatureModule module() {
        if (module == null && activity != null) module = new MyFeatureModule(activity, this::pushEvent);
        return module;
    }

    @UsedByGodot
    public void do_something(String arg) {
        MyFeatureModule m = module();
        if (m != null) m.doSomething(arg);
    }

    @UsedByGodot
    public boolean has_pending_event() {
        return !pendingEvents.isEmpty();
    }

    @UsedByGodot
    public Dictionary pop_pending_event() {
        Dictionary data = pendingEvents.poll();
        return data != null ? data : new Dictionary();
    }
}

Bọc GDScript Wrapper có Safe-Mock

Tạo addons/my_feature/MyFeature.gd: rút queue, tách signal, giả lập an toàn trên PC.
# Mô tả ngắn gọn addon (Hạ tầng dùng chung)
extends Node

const PLUGIN_NAME := "GodotMyFeature"

signal something_done(result: Dictionary)
signal something_failed(code: int, message: String)

var _plugin: Object = null


# Kết nối chuông báo từ Java, payload thật luôn rút từ queue
func _ready() -> void:
	if not Engine.has_singleton(PLUGIN_NAME):
		return
	_plugin = Engine.get_singleton(PLUGIN_NAME)
	if _plugin.has_signal("event_ready"):
		_plugin.event_ready.connect(_drain_pending_events)
	# Đợi 1 frame để node khác kịp connect signal rồi mới rút sự kiện tồn đọng
	get_tree().process_frame.connect(_drain_pending_events, CONNECT_ONE_SHOT)


# Rút hết queue để không mất sự kiện lúc cold start
func _drain_pending_events() -> void:
	if not is_available():
		return
	while _plugin.has_pending_event():
		var event: Dictionary = _plugin.pop_pending_event()
		if event.is_empty():
			break
		_dispatch_event(event)


# Tách sự kiện chung thành signal có nghĩa cho game
func _dispatch_event(event: Dictionary) -> void:
	if str(event.get("type", "")).ends_with("_failed"):
		something_failed.emit(int(event.get("code", -1)), str(event.get("message", "")))
	else:
		something_done.emit(event)


# Kiểm tra xem plugin native có đang hoạt động hay không
func is_available() -> bool:
	return _plugin != null


# PC/Editor không có native nên trả kết quả giả qua call_deferred
func do_something(arg: String) -> void:
	if is_available():
		_plugin.do_something(arg)
	else:
		something_done.emit.call_deferred({"type": "done", "mock": true, "arg": arg})
  • Mọi hàm public đều có nhánh is_available(). Nhánh mock không được gọi vào _plugin.
  • Signal mock phát qua call_deferred, không phát đồng bộ ngay trong lúc game đang gọi hàm.
  • Hàm có giá trị trả về phải trả giá trị mặc định an toàn ({}, "", false, hoặc giá trị hợp lý).
  • Không đặt text, ID sản phẩm hay logic thưởng của game trong wrapper.

Cấu hình Export & bàn giao

Tạo plugin.cfg và export_plugin.gd, bật plugin, kiểm tra export preset, rồi bàn giao core sang repo game.
[plugin]

name="GodotMyFeature"
description="Mo ta ngan gon addon."
author="NextGZ"
version="0.1.0"
script="export_plugin.gd"
@tool
extends EditorPlugin

const PLUGIN_NAME := "GodotMyFeature"
const AAR_RELEASE := "res://addons/my_feature/bin/GodotMyFeature-release.aar"
const AUTOLOAD_NAME := "MyFeature"
const AUTOLOAD_PATH := "res://addons/my_feature/MyFeature.gd"

# Phải trùng version với implementation(...) trong build.gradle.kts
const ANDROID_DEPENDENCIES := [
	"com.example:some-sdk:1.2.3",
]

var _export_plugin: AndroidExportPlugin

func _enter_tree() -> void:
	_export_plugin = AndroidExportPlugin.new()
	add_export_plugin(_export_plugin)
	add_autoload_singleton(AUTOLOAD_NAME, AUTOLOAD_PATH)

func _exit_tree() -> void:
	remove_autoload_singleton(AUTOLOAD_NAME)
	if _export_plugin != null:
		remove_export_plugin(_export_plugin)
		_export_plugin = null

class AndroidExportPlugin extends EditorExportPlugin:
	func _get_name() -> String:
		return PLUGIN_NAME

	func _supports_platform(platform: EditorExportPlatform) -> bool:
		return platform is EditorExportPlatformAndroid

	func _get_android_libraries(_platform: EditorExportPlatform, _debug: bool) -> PackedStringArray:
		return PackedStringArray([AAR_RELEASE])

	func _get_android_dependencies(_platform: EditorExportPlatform, _debug: bool) -> PackedStringArray:
		return PackedStringArray(ANDROID_DEPENDENCIES)

	func _get_android_dependencies_maven_repos(_platform: EditorExportPlatform, _debug: bool) -> PackedStringArray:
		return PackedStringArray(["https://maven.google.com"])

	# Manifest của AAR đã có meta-data này và Gradle tự gộp; khai lại để nhìn file export là thấy đủ cấu hình
	func _get_android_manifest_application_element_contents(_platform: EditorExportPlatform, _debug: bool) -> String:
		return """
		<meta-data
			android:name="org.godotengine.plugin.v2.GodotMyFeature"
			android:value="com.godot.myfeature.GodotMyFeaturePlugin" />
		"""

Kích hoạt & kiểm tra

  1. Godot Editor → Project Settings → Plugins → bật GodotMyFeature. Godot sẽ tự thêm Autoload và sinh file .uid, không sửa tay project.godot.
  2. Export preset Android: gradle_build/use_gradle_build=true (đã bật sẵn trong export_presets.cfg). Lần đầu dùng: Project → Install Android Build Template.
  3. Chạy game trên PC để xác nhận Safe-Mock không lỗi, rồi export lên máy thật và xem logcat theo tag của plugin.

Bàn giao sang repo Game

  • Chỉ giữ core hạ tầng. Không tạo scene hoặc UI test trong repo addon.
  • Commit custom_plugin/my_feature/ (không commit build/, .gradle/, local.properties) cùng toàn bộ addons/my_feature/, kể cả file .aar.
  • Repo game chỉ cần copy thư mục addons/my_feature/ rồi bật plugin.

Checklist trước khi merge addon mới

  • Tên singleton khớp ở cả 5 vị trí (Gradle, Java, Manifest, wrapper, export).
  • Không có emitSignal nào gọi trực tiếp từ callback OS hoặc SDK. Tất cả đi qua queue.
  • Dependency trong export_plugin.gd trùng version với build.gradle.kts.
  • Không thêm quyền nguy hiểm hoặc bị hạn chế (SCHEDULE_EXACT_ALARM, …).
  • Wrapper chạy trên PC không lỗi, mọi hàm đều có Safe-Mock.
  • Mỗi hàm 5–15 dòng, comment một dấu # tiếng Việt giải thích lý do, không có magic number.
  • Không có tên game, text hiển thị hay logic thưởng trong addon.
  • File .aar trong addons/<tên>/bin/ được build lại từ đúng commit Java mới nhất.
